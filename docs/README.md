# Documentación

Consultar la entrega en la que se está trabajando. Solo el contexto y las decisiones comunes viven fuera de las entregas.

- [Entrega 2](entrega-02/README.md): auditoría, EDA, ETL, resultados e informe. Incluye [guía del notebook](entrega-02/guia-resumen-notebook.md).
- [Entrega 3](entrega-03/README.md): preparación del modelado; agregar aquí su informe, resultados y figuras.
- [Contexto transversal](transversal/contexto.md): objetivo, fuentes y trabajo en equipo.
- [Decisiones del proyecto (ADR)](adr/README.md): reglas y justificaciones compartidas entre entregas.

```text
docs/
  adr/          decisiones del proyecto
  entrega-02/    documentación y materiales de esta entrega
  entrega-03/    documentación y materiales de esta entrega
  transversal/  contexto y fuentes comunes
  README.md
```

Al comenzar otra entrega, crear `entrega-NN/` con su README y agregarla a este índice. Guardar sus materiales dentro de esa carpeta; no crear clasificaciones globales para figuras o informes. Actualizar los ADR solo cuando cambie una regla del proyecto. Las versiones anteriores se consultan en Git, sin mantener copias históricas paralelas.
